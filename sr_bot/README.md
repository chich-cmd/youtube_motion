# sr_bot — 차트술사 기준선 스캐너

차트술사 지지저항 이론을 판정 규칙으로 옮긴 스캐너입니다.
한국·미국 주식의 확정 봉(일·주·월)에서 기준선을 찾고, 현재가와의 관계로 눌림·저점·도지·돌파 후보를 분류해
진입·철회·목표가 들어간 리포트(HTML/PDF/CSV)를 만듭니다. 자동 주문은 하지 않습니다.

## 이론 → 코드 대응

기준 문서: 「지지저항 구조를 기반한 차트 트레이딩 연구」 + **「차트술사 차트 이론 완전판」(2026-10-24, PART 1~21 전체)**.
완전판이 [확정]으로 둔 규칙은 그대로 옮기고, 수치가 미확정인 항목(PART 19)은 **구현 설정값**으로 따로 표시합니다.
리포트 끝에도 "확정 규칙"과 "구현 설정값"을 나눠 적습니다.

### 확정 규칙 → 구현

| 완전판 | 구현 |
|---|---|
| 사건봉: 직전 20봉(현재 봉 제외) 평균 대비 **거래대금 3배 이상 + 300억 원 이상**(국내 일봉) | `levels.detect_bar_levels` · 사건봉 종가 = 보조 기준선 |
| 조정봉: 사건봉 **바로 다음 봉**(색·모양 무관), 종가 = **핵심 탐색 기준선** | 같은 곳. 두 가격을 함께 저장 |
| 조정봉 종가를 아래→위 종가 돌파 = **관심종목 편입**(매수 아님) | 탐색 엔진 C (`strategy.scan_events`), 리포트 "탐색 엔진" 표 |
| 종가가 결재권자, 꼬리 침범 허용·**몸통과 종가가 선 위**여야 지지 | `_held` |
| 돌파 ≠ 지지 확인. 상태: 저항 관찰 → 종가 돌파 → 지지 전환 후보 → 눌림 후보 → **지지 확인(유지+반등)** → 무효화 | `_retest`. 매매 조건 충족은 지지 확인부터 |
| 도지 상단·종가·하단. 내부: 종가~하단 매수 우위, 하단 종가 이탈 실패. 외부 롱: **1차 상단, 2차 종가, 하단 이탈 최종 실패** | `_box_setup` (도지 유형) |
| 박스 상단·내부 종가선·하단. 1파 돌파 → **2파 눌림** → 3파. 돌파 후 철회선(상단 재침범/하단 이탈)은 진입 시 선택 | `_box_setup` (박스 유형), `box_fail` 설정 |
| 갭 발생봉 종가 기준선 (갭 유형 ①② 구분은 미확정이라 방향만) | `gap_close` 선 |
| 선의 격: 연봉 > 월봉 > 주봉 > 일봉. 상위 선의 구조 붕괴는 그 시간봉 종가로, 포지션 손절은 따로 | 연봉 종가선(`year_close`), 철회 조건 문구에 구조 판정 프레임 표시 |
| 매매법 3종: 눌림(주력) · 돌파(종가 확인 후는 별개 전략) · 저점(선제 진입, 손절 중요) | 유형 눌림·돌파·저점 + 도지·박스 |
| 익절은 다음 저항(과거 거래 가격·상위 저항·도지·박스·클러스터) | 1·2차 목표. 근거 약한 일봉 박스 선만 있는 가격대는 건너뜀 |
| 기준선 DB(사건봉·조정봉 날짜·가격·상대배수·상태·이벤트 날짜), 과거 선은 시간만으로 지우지 않음 | `*_lines.csv` |
| 보조지표(이평·RSI·VWAP·일목·MACD)는 판정을 대체하지 않음 | 점수 제외, 이평 배열만 참고 표시 |
| 조건이 없으면 무포지션 | 리포트 상단 "무포지션 유지" 표시 |

### 구현 설정값 (차트술사 규칙 아님)

| 항목 | 기본값 | 비고 |
|---|---|---|
| 미국 사건봉 절대 거래대금 | 없음(상대 3배만) | 완전판 18-6: 미확정 |
| 주·월봉 사건봉 절대 거래대금 | 국내 300억 동일 적용 | 일봉 기준만 확정 |
| 직전 20봉 중 거래 없는 봉이 있으면 사건봉 제외 | 적용 | 신규 상장·거래정지 직후 배수 왜곡 방지 |
| 기준선 접근 범위 / 반등 확인 봉 수 | 일 1.5% · 주 3% · 월 5% / 3봉 | 2% 접근 = 지지 성공이 아님 |
| 박스가 되는 봉 | 사건봉 다음 봉 도지, 추세전환 직전 봉, 거래량 3배 봉, 횡보 박스 | 사용자 정의 + 7장 횡보 박스 |
| 횡보 박스 | 20봉 이상, 고저 폭 ≤ 15%(일), 상·하단 각 2회 반응 | 길이·반응 조건 미확정 |
| 도지 몸통 비율 | ≤ 30% | 미확정 |
| 박스 돌파 후 철회 | `box_fail = "low"` (high/close/low 선택) | 사용자 선택 |
| 최소 순손익비 / 손절 폭 / 유동성 | 1.5 / 8% / 20일 거래대금 중앙값 10억 원 | 최소 손익비 미확정 |
| 분할매수·익절 | 2분할 / 1차 50%→2차 50%, 1차 후 본전컷 | 30·30·40은 신고가 연구 예시 |
| 격·적합도 점수 가중치 | 코드 참고 | 미확정 — 순위 참고용 |

아직 반영하지 않은 것: 숏 시나리오(도지 하단 이탈 숏 등), 수급(투자자별 매매), 시장 전체 등락·섹터 로테이션 통계, 신고가 구간의 스윙로우 추세 추종 관리.

## 설치

```bash
cd sr_bot
pip install -r requirements.txt
python -m pytest -q tests        # 오프라인 테스트
python -m sr_bot demo            # 가상 데이터로 리포트 예시 생성 → reports/
```

## 사용

```bash
# 한국 주봉 (KOSPI+KOSDAQ 전체, 우선주·스팩·리츠 제외)
python -m sr_bot scan --market kr --tf W

# 미국 일봉 (S&P 500 + Nasdaq-100)
python -m sr_bot scan --market us --tf D --universe all

# 특정 종목만, 계좌 3천만 원 기준 수량까지
python -m sr_bot scan --market kr --tf D --universe 005930,000660 --account 30000000

# 과거 기준일로 다시 스캔
python -m sr_bot scan --market us --tf D --universe CRWD --asof 2026-09-14

# 인터넷 없이: 종목별 일봉 CSV 폴더로 실행 (파일명 = 코드 또는 코드_이름.csv,
# 열 = date/open/high/low/close/volume 또는 날짜/시가/고가/저가/종가/거래량)
python -m sr_bot scan --market kr --tf W --data-dir ./my_csv

# PDF도 함께 저장 (pip install playwright && playwright install chromium)
python -m sr_bot scan --market kr --tf W --pdf

# 백테스트: 점수 구간별·프레임별 성과
python -m sr_bot backtest --market us --tf D --universe ndx --years 10
```

결과는 `reports/`에 HTML(상위 20 표 + 상세 카드 + 차트 + 업종 분포)과 CSV(구조가 발견된 전체 종목)로 저장됩니다.
`--telegram`을 붙이면 요약과 HTML 파일을 텔레그램으로 보냅니다 (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 필요).

설정은 `config.toml`에서 바꿉니다. 프레임별 세부값은 `sr_bot/config.py`의 `TFParams`를 참고해
`[tf_params.W]` 같은 표로 덮어쓰면 됩니다.

## 자동 실행 (GitHub Actions)

`.github/workflows/sr_bot.yml`
- 평일 16:43 KST: 한국 일봉, 금요일에는 주봉도
- 평일 미국 장 마감 후: 미국 일봉, 금요일에는 주봉도
- 리포트는 Actions 아티팩트로 30일 보관, 텔레그램 시크릿이 있으면 전송

저장소 Settings → Secrets and variables → Actions에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 등록하세요.
KRX 계정이 있으면 `KRX_ID`, `KRX_PW`를 넣어 pykrx로 받습니다. 없으면 FinanceDataReader(네이버)를 씁니다.
백테스트는 `sr_bot backtest` 워크플로를 수동 실행합니다.

## 백테스트 규칙

- t 시점에는 t까지의 데이터로만 판정합니다 (각 선의 확정 시점 `born` ≤ t, 클러스터는 일정 간격으로 그 시점까지 데이터로 재계산).
- 매매 조건 충족 + 적격이면 다음 봉 시가에 진입합니다. 시가가 철회선 아래이거나 구간 상단보다 1% 넘게 위면 진입하지 않습니다.
- 1차 목표에서 절반 익절 후 남은 절반은 본전 손절·2차 목표, 종가가 철회선 아래면 다음 봉 시가에 청산, `max_hold`봉이 지나면 종가로 청산합니다.
- 비용은 신호 시점의 유동성으로 계산한 왕복 비용을 차감합니다.
- 상장폐지 종목이 빠진 현재 종목 목록을 쓰므로 생존 편향이 있습니다. 결과를 보수적으로 해석하세요.

검증 참고: 추세가 없는 무작위 가격(가상 데이터)에서는 기대값이 0 부근에서 비용만큼 음수로 나와야 정상입니다.
미래 데이터를 참조하는 버그가 없다는 확인일 뿐, 실제 시장 성과가 아닙니다.
**실제 성과는 실제 데이터로 백테스트한 뒤 판단해야 합니다.**

## 알려진 한계

- 공부법은 숫자 기준을 주지 않으므로 거래량 배수, 도지 비율, 재접근 폭 등은 초기값입니다. 백테스트로 조정하세요.
- 도지 3유형 중 "추세 변곡 도지"는 해석이 필요해 자동 분류하지 않았습니다. 돌파매매·저점매매도 아직 신호로 만들지 않았습니다.
- 휴장일 달력을 쓰지 않고, 대부분 종목이 가진 마지막 거래일을 기준일로 씁니다.
- 네이버 일봉에 NXT 시간외 가격이 섞이는지는 확인하지 않았습니다. 정확한 KRX 종가가 필요하면 KRX 계정(pykrx)을 쓰세요.
- 공시·재무·뉴스는 반영하지 않습니다. 적합도 점수는 상승확률이 아닙니다.
