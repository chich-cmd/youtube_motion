# sr_bot — 지지저항 구조 눌림매매 스캐너

「지지저항 구조를 기반한 차트 트레이딩 연구」의 규칙을 코드로 옮긴 스캐너입니다.
한국·미국 주식의 확정 봉(일·주·월)에서 기능선을 찾고, **돌파 → 종가 유지 → 재접근 지지** 구조인 종목을
골라 진입가·손절가·익절가가 들어간 리포트를 만듭니다. 자동 주문은 하지 않습니다.

## 공부법 → 코드 대응

| 공부법 | 구현 |
|---|---|
| 지지저항선은 종가로 기능이 바뀌는 스위치선 | 모든 판정은 종가 기준 (`strategy.evaluate`) |
| 기준봉: 고거래량 봉의 종가 | 직전 20봉 평균 거래량의 2배 이상인 봉의 종가 |
| 도지 전장 (장대봉 후 조정 도지 / 추세 강화 도지) | 몸통 ≤ 전체 길이의 30%, 장대봉 후 3봉 이내 또는 강한 같은 방향 봉 3개 이후. 상단·하단·종가 모두 선 |
| 종가 클러스터 | 최근 N개 종가 중 ±1~2% 폭에 5~6개 이상 몰린 가격대. 대표값은 실제 종가 하나 |
| 격 | 선이 지지(hold)·저항(reject)·전환(flip)을 수행한 횟수 + 상위 프레임·여러 프레임 겹침·초고거래량 가점 |
| 눌림매매 (주력) | 돌파 전 저항 흔적 → 종가 돌파 → 이후 종가 이탈 없음 → 선 부근 재접근 후 종가 지지 |
| 공통 실패 조건 | 기능선 아래 종가 마감 = 즉시 실패. 손절 추정가 = 기능선 − 슬리피지 |
| 부록 A (세계관 최강자선) | 과거 700봉 최대 거래량 양봉 → 초고거래량 표시, 오래전 돌파여도 재접근 허용 |
| 부록 B (감자숏) | 공매도 대신 "거래량 없는 돌파" 경고 + 감점 |
| 1장 리스크 관리 | `account`를 넣으면 1회 손실 ≤ 계좌 × `risk_per_trade` 수량 계산 |

이동평균 배열과 주봉 저점 상승은 공부법에 없는 지표라서 **점수에 넣지 않고 참고 정보로만** 표시합니다.

기존 리포트와 다르게 처리한 점:
- 기능선은 실제 봉 가격만 쓰므로 호가 단위에 항상 맞습니다. 계산으로 만든 가격(구간 상단, 손절 추정, 목표)은 호가 단위로 반올림합니다.
- 비용은 고정 0.4%가 아니라 거래대금이 낮을수록 크게 잡습니다 (`slippage_tiers`).
- '지지 확인' 종목이 0개인 회차에는 리포트 맨 위에 그 사실을 표시합니다.
- 최신 봉이 기준일보다 오래된 종목, 이력 부족, 거래정지, 가격 불연속(분할 미반영 의심)은 "자료 미검증"으로 따로 셉니다.
- 배당까지 수정한 주가는 과거 종가를 바꾸므로 쓰지 않습니다 (분할만 반영).

## 설치

```bash
cd sr_bot
pip install -r requirements.txt
python -m pytest -q tests        # 오프라인 테스트
python -m sr_bot demo            # 가상 데이터로 리포트 예시 생성 → reports/
```

## 사용

```bash
# 한국 주봉 (KOSPI+KOSDAQ 전체, 우선주·스팩·리츠 제외)
python -m sr_bot scan --market kr --tf W

# 미국 일봉 (S&P 500 + Nasdaq-100)
python -m sr_bot scan --market us --tf D --universe all

# 특정 종목만, 계좌 3천만 원 기준 수량까지
python -m sr_bot scan --market kr --tf D --universe 005930,000660 --account 30000000

# 과거 기준일로 다시 스캔
python -m sr_bot scan --market us --tf D --universe CRWD --asof 2026-09-14

# 인터넷 없이: 종목별 일봉 CSV 폴더로 실행 (파일명 = 코드 또는 코드_이름.csv,
# 열 = date/open/high/low/close/volume 또는 날짜/시가/고가/저가/종가/거래량)
python -m sr_bot scan --market kr --tf W --data-dir ./my_csv

# PDF도 함께 저장 (pip install playwright && playwright install chromium)
python -m sr_bot scan --market kr --tf W --pdf

# 백테스트: 점수 구간별·프레임별 성과
python -m sr_bot backtest --market us --tf D --universe ndx --years 10
```

결과는 `reports/`에 HTML(상위 20 표 + 상세 카드 + 차트 + 업종 분포)과 CSV(구조가 발견된 전체 종목)로 저장됩니다.
`--telegram`을 붙이면 요약과 HTML 파일을 텔레그램으로 보냅니다 (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` 필요).

설정은 `config.toml`에서 바꿉니다. 프레임별 세부값은 `sr_bot/config.py`의 `TFParams`를 참고해
`[tf_params.W]` 같은 표로 덮어쓰면 됩니다.

## 자동 실행 (GitHub Actions)

`.github/workflows/sr_bot.yml`
- 평일 16:43 KST: 한국 일봉, 금요일에는 주봉도
- 평일 미국 장 마감 후: 미국 일봉, 금요일에는 주봉도
- 리포트는 Actions 아티팩트로 30일 보관, 텔레그램 시크릿이 있으면 전송

저장소 Settings → Secrets and variables → Actions에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 등록하세요.
KRX 계정이 있으면 `KRX_ID`, `KRX_PW`를 넣어 pykrx로 받습니다. 없으면 FinanceDataReader(네이버)를 씁니다.
백테스트는 `sr_bot backtest` 워크플로를 수동 실행합니다.

## 백테스트 규칙

- t 시점에는 t까지의 데이터로만 판정합니다 (각 선의 확정 시점 `born` ≤ t, 클러스터는 일정 간격으로 그 시점까지 데이터로 재계산).
- '지지 확인' + 적격이면 다음 봉 시가에 진입합니다. 시가가 기능선 아래이거나 구간 상단보다 1% 넘게 위면 진입하지 않습니다.
- 고가가 1차 목표에 닿으면 전량 익절, 종가가 기능선 아래면 다음 봉 시가에 손절, `max_hold`봉이 지나면 종가로 청산합니다.
- 비용은 신호 시점의 유동성으로 계산한 왕복 비용을 차감합니다.
- 상장폐지 종목이 빠진 현재 종목 목록을 쓰므로 생존 편향이 있습니다. 결과를 보수적으로 해석하세요.

검증 참고: 추세가 없는 무작위 가격(가상 데이터 12종목 × 2,500봉)에서는 평균 −0.04R(469건)로 비용만큼 음수가 나왔습니다.
미래 데이터를 참조하는 버그가 없다는 확인일 뿐, 실제 시장 성과가 아닙니다.
**실제 성과는 실제 데이터로 백테스트한 뒤 판단해야 합니다.**

## 알려진 한계

- 공부법은 숫자 기준을 주지 않으므로 거래량 배수, 도지 비율, 재접근 폭 등은 초기값입니다. 백테스트로 조정하세요.
- 도지 3유형 중 "추세 변곡 도지"는 해석이 필요해 자동 분류하지 않았습니다. 돌파매매·저점매매도 아직 신호로 만들지 않았습니다.
- 휴장일 달력을 쓰지 않고, 대부분 종목이 가진 마지막 거래일을 기준일로 씁니다.
- 네이버 일봉에 NXT 시간외 가격이 섞이는지는 확인하지 않았습니다. 정확한 KRX 종가가 필요하면 KRX 계정(pykrx)을 쓰세요.
- 공시·재무·뉴스는 반영하지 않습니다. 적합도 점수는 상승확률이 아닙니다.
